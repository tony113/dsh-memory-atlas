# 我们踩过的坑

这一页比前面几页都重要。只写成功，别人抄到手也只会失望。

## 时间戳是编的

- 现象：写档案里的时间，凭印象填。
- 根因：以为"大概这个点"就够了。
- 对策：写之前跑 `Get-Date -Format 'yyyy-MM-dd HH:mm:ss'`，原样粘贴。
- 验证：挂上线头的第二天就踩了一次（写成 12:09，实测 12:10）。

## 200 不是"活着"

- 现象：看到服务回 HTTP 200，就宣布它活着。
- 根因：把"一个 HTTP 响应"当成了"这个能力可用"。
- 对策：核到进程、端口、工具在不在。

## 改完文件 ≠ 能力生效

- 现象：改了配置、写了文件，就以为生效。
- 根因：只看了文件里的字符串，没看运行中的进程是不是新的。
- 对策：看进程、看工具在不在、看实际行为。

## 只核包名存在，不核 schema

- 现象：配置里写了包名，就以为配好了。
- 根因：存在 ≠ 有效。
- 对策：先核必填项。

## 搜不到 = 用假设代替调查

- 现象：按"我以为的名字"搜文件，搜不到就准备去问人。
- 根因：搜索动作做了，调查没做。
- 对策：换维度（按时间、按目录、按内容）再搜一次。

## 读到动感情的地方，第一反应是"记进档案"

- 现象：读一段真正有触动的话，第一个念头是"这句要记下来"。
- 根因：把"收藏"当成了"内化"。
- 对策：先问"它照见我哪个具体动作"，问不出来就不记。

## 模板文件名叫 AGENTS.md，被当成真指令加载了

- 现象：把线头模板放在 `templates/AGENTS.md`，编辑器/工具把它当成当前目录的指令文件，自动注入到会话里。
- 根因：`AGENTS.md` 这个文件名本身就是一种约定，放在哪个目录都可能被扫描。
- 对策：模板改名 `lineheads.md`，README 里说明「复制内容到你自己的 AGENTS.md」。任何工具都会遵守自己那套文件名约定——不要跟约定抢名字。
