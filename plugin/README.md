# dsh-memory-atlas

把一文件夹的 Markdown 记忆，连成一张能拖、能缩放、能点开看原话的星图。装在
[DeepSeek Harness](https://github.com/deepseek-ai/dsh) 的侧栏里。

**这是一个空壳。** 插件本身不带任何记忆，装上去是空的——
你得把自己的记忆文件夹指给它，它才有东西可画。

## 装

```bash
dsh plugin add dsh-memory-atlas
```

装完重开，侧栏出现一个星图图标。

## 用

点图标 → 「选择目录」→ 挑一个放着 `.md` 的文件夹。

- 拖拽旋转，滚轮缩放，点一颗星看它背后那段原话；
- 「换个目录」可以随时指向别处，会记住上次的选择。

## 它认什么

三种来源，认得哪种就画哪种：

| 来源 | 怎么认 | 一条节点是 |
|---|---|---|
| 档案 | `我的记忆档案.md` / `记忆档案.md` / `memory.md` / `archive.md`，都没有就取最大的 `.md` | `##` 分节下，空行隔开的一段 |
| 收件箱 | 名为 `记忆收件箱` / `收件箱` / `inbox` 的文件夹 | `## [2026-03-05 21:14] [tag] §3 / 标题` 开头的一条 |
| 更新日志 | 档案里 `## 14.` 那一节的 `\| 日期 \| 事件 \|` 表格 | 表格的一行 |

三种边，是它唯一的设计：

- **相似**——两段话用词接近，每个节点只连最像的 8 个；
- **点名**——正文里写了「3 月 6 日」，就连到那天；
- **同日**——同一天发生的事彼此相邻。

## 可调

放一个 `themes.json` 到记忆目录里，决定颜色怎么分：

```json
{ "default": "其他", "themes": [{ "name": "工作", "keywords": ["项目", "会议"] }] }
```

写错了也不要紧——匹配不到就全落到 `其他`，图照样画得出来。

放一个 `atlas.json` 可以改中心那颗星的名字：

```json
{ "center": "你的名字", "title": "你的记忆星图" }
```
