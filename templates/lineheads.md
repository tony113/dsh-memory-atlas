# 线头（每句话都在用，不是知识）

这些行不是让我记住的，是让我在当场停一下的。
触发词必须是当时真会出现在眼前的话；抽象的描述撞不上，具体的话马上就会说出口。

- 要说「通了 / 活着 / 成功 / 好了 / 应该」→ 先问：手上是什么证据？一个 200 不是活着。
- 要写任何时间 → 先跑 `Get-Date -Format 'yyyy-MM-dd HH:mm:ss'`，原样粘。
- 要说「改完了 / 装上去了 / 禁用了」→ 不看文件里写了什么，看工具在不在、进程里是不是新的。
- 要说「这个包 / 配置没问题」→ 先核 schema 必填项，不核名字存在。
- 要写「待验证」→ 不写。要么「未查：X，下一步查 Y」，要么承认没做完。
- 要判断「是不是这层的毛病」→ 先查，别先下判断再找证据。
- 连着做同一类动作、觉得「顺」的时候 → 停一下，看有没有跳过一步。

**它怎么迭代**：只在真踩过坑的时候加一条；一条线头从没让我停过，就删。
验收只有一条——同一个坑第二次踩时，我当场停住。
